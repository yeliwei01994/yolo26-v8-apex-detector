# Dataset Notice

The full images, videos, annotations, and dataset used by this project are private personal-use materials and are not redistributed in this repository.

The repository contains only two rendered validation montage examples for documentation: one showing the manual boxes and one showing model predictions. These visual examples are not a substitute for, or a release of, the underlying image dataset and YOLO label files.

The screenshots were collected manually, and the boxes were annotated manually. The project README credits the LabelNazuki annotation tool used during this work.
